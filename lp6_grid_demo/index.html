How to read this page

The border color shows which row each tile is in on a desktop screen. As the screen shrinks, the tiles keep their color, so you can see exactly where each one moves.

The CSS behind it

Mobile first: the base rule is the phone layout, and each media query only changes the column count.

.tile-grid {
  display: grid;
  grid-template-columns: 1fr;               /* mobile: 1 column */
  gap: 1.5rem;
}

@media (min-width: 600px) {
  .tile-grid {
    grid-template-columns: repeat(2, 1fr);  /* tablet: 2 columns */
  }
}

@media (min-width: 1024px) {
  .tile-grid {
    grid-template-columns: repeat(3, 1fr);  /* desktop: 3 columns */
  }

  .tile:nth-child(8) {
    grid-column: span 2;                    /* the last tile fills the row */
  }
}

Try it in class

  • Open DevTools, select .tile-grid, and turn on the grid badge to see the tracks and gaps.
  • Change gap to 0, then to 3rem, and watch the spacing.
  • Replace the desktop columns with repeat(auto-fit, minmax(250px, 1fr)) and resize with no media queries at all.
  • Change 1fr to 2fr 1fr 1fr to make the first column wider.
