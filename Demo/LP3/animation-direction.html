animation-direction

Four values, and the difference between normal and alternate is exactly what causes — or fixes — a visible snap.

animation-direction — normal vs. alternate

Both pulse identically in one direction. Watch closely at the end of each cycle: normal jumps back to the start; alternate reverses smoothly — no jump.

normaljumps at loop point
alternatereverses smoothly
index.html 
<div class="shape ad-normal">normal</div>
<div class="shape ad-alternate">alternate</div>
style.css 
@keyframes grow {
  0%   { transform: scale(1); }
  100% { transform: scale(1.15); }
}

/* normal (default): always plays 0% → 100%, then jumps back to repeat */
.ad-normal {
  animation: grow 1.2s ease-in-out infinite;
  animation-direction: normal;
}

/* alternate: plays 0%→100%, then reverses 100%→0% — no jump */
.ad-alternate {
  animation: grow 1.2s ease-in-out infinite;
  animation-direction: alternate;
}
