prefers-reduced-motion

A media query wrapping a reset — four properties, each neutralizing one kind of motion.

prefers-reduced-motion — The Global Reset

This box respects your OS's motion setting. Enable Reduce Motion in your system accessibility settings and reload this page — the animation below will stop completely instead of just slowing down.

Watching your
OS setting

Mac: System Settings → Accessibility → Display → Reduce Motion. Windows: Settings → Accessibility → Visual effects → Animation effects (off).

index.html 
<div class="shape prm-box">Watching your OS setting</div>
style.css 
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.08); }
}
.prm-box {
  animation: pulse 1.5s ease-in-out infinite;
}

/* ===== REDUCED MOTION RESET — add this once, globally ===== */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration:        0.01ms !important;
    animation-iteration-count: 1     !important;
    transition-duration:       0.01ms !important;
    scroll-behavior:           auto   !important;
  }
}
