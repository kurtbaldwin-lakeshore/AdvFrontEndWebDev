DT 3.1

transition-timing-function

Five built-in keywords cover most cases; cubic-bezier() gives full custom control when you need it.

Easing — Try Hovering Each

Same distance, same duration — the only thing that changes is the acceleration curve.

index.html 
<button class="shape ez ez-ease">ease</button>
<button class="shape ez ez-in">ease-in</button>
<button class="shape ez ez-out">ease-out</button>
<button class="shape ez ez-inout">ease-in-out</button>
<button class="shape ez ez-linear">linear</button>
<button class="shape ez ez-bezier">cubic-bezier()</button>
style.css 
.ez-ease:hover,   .ez-ease:focus-visible   { transition-timing-function: ease; }
.ez-in:hover,     .ez-in:focus-visible     { transition-timing-function: ease-in; }
.ez-out:hover,    .ez-out:focus-visible    { transition-timing-function: ease-out; }
.ez-inout:hover,  .ez-inout:focus-visible  { transition-timing-function: ease-in-out; }
.ez-linear:hover, .ez-linear:focus-visible { transition-timing-function: linear; }

/* Custom curve — "bouncy", overshoots then settles */
.ez-bezier:hover,
.ez-bezier:focus-visible {
  transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
}

.ez {
  transition-property: transform;
  transition-duration: 0.6s;
}
.ez:hover,
.ez:focus-visible { transform: translateY(-16px); }
