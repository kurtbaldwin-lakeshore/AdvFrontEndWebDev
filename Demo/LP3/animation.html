animation

Seven sub-properties, each controlling one aspect independently — or combine the common ones into shorthand.

animation — fill-mode Comparison

Both boxes run the identical animation once, on page load. Without fill-mode: both, the element snaps back to its pre-animation state the instant the animation ends — watch closely as the page loads, or reload to see it again.

No fill-modesnaps back
fill-mode: bothstays in place
index.html 
<div class="shape an-nofill">No fill-mode</div>
<div class="shape an-fill">fill-mode: both</div>
style.css 
@keyframes slideIn {
  from { transform: translateX(-30px); background: #93c5fd; }
  to   { transform: translateX(20px); background: #a65314; }
}

/* Shorthand: name duration timing-function — no fill-mode */
.an-nofill {
  animation: slideIn 1s ease-out;
}

/* Shorthand: name duration timing-function fill-mode */
.an-fill {
  animation: slideIn 1s ease-out both;
}
