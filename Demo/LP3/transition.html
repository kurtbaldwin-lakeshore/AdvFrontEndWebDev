transition — Try Hovering

Four sub-properties in one shorthand: what changes, how long it takes, the easing curve, and an optional delay.

<button class="shape tr-single">Single Property</button>
<button class="shape tr-multi">Multiple Properties</button>
style.css 
/* Full shorthand: property duration timing-function delay */
.tr-single:hover,
.tr-single:focus-visible {
  transition: transform 0.25s ease-out;
  transform: translateY(-8px);
}

/* Comma-separated: multiple properties, each can have its own timing */
.tr-multi:hover,
.tr-multi:focus-visible {
  transition:
    transform 0.25s ease-out,
    box-shadow 0.25s ease-out,
    background-color 0.4s ease;
  transform: translateY(-8px);
  box-shadow: 0 10px 20px rgba(0,0,0,.3);
  background-color: #a65314;
}
