@media (min-width)

Base styles apply everywhere; each min-width query only adds what changes at that width and above.

@media (min-width) — Resize the Window

Base styles apply everywhere. Each min-width query only adds what changes at that width and above — shrink your browser window to see the badge change.

Mobile layout (below 700px) Desktop layout (700px and up)
index.html 
<div class="badge">
  <span class="label-mobile">Mobile layout</span>
  <span class="label-desktop">Desktop layout</span>
</div>
style.css 
/* Base styles (mobile-first): show the mobile label, hide desktop */
.label-desktop { display: none; }

/* At 700px and up: flip which label shows */
@media (min-width: 700px) {
  .label-mobile  { display: none; }
  .label-desktop { display: inline; }
}
