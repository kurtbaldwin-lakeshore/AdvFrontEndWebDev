DT 5.2

align-self and order

Overriding alignment or visual order for one specific item.

align-self — Override for One Item

The container stretches every item to full height by default. One item opts out with align-self.

Default
Default
align-self: flex-start
index.html 
<div class="row">
  <div class="item">Default</div>
  <div class="item">Default</div>
  <div class="item self-start">align-self: flex-start</div>
</div>
style.css 
.row { display: flex; align-items: stretch; gap: 1rem; }

.item.self-start {
  align-self: flex-start;   /* opts out of stretch, keeps natural height */
}

order — Visual Position Only

The HTML order stays 1, 2, 3 — only what you SEE changes. Keyboard Tab order still follows the markup, not the visual position.

1 in HTML
2 in HTML
3 in HTML, order: -1
index.html 
<div class="item">1 in HTML</div>
<div class="item">2 in HTML</div>
<div class="item order-first">3 in HTML</div>
style.css 
.item.order-first {
  order: -1;   /* moves it first visually, HTML order unchanged */
}
