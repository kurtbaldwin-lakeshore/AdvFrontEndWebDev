DT 5.2

Flex Container vs. Flex Item Properties

Container properties arrange the group; item properties control one item within it.

Flex Container Properties

Applied to the display: flex element itself — they control how the ITEMS are arranged as a group.

1
2
3
index.html 
<div class="row">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
style.css 
.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Flex Item Properties

Applied to direct children — they control how ONE item behaves within the group.

grows
fixed
fixed
index.html 
<div class="item grow">grows</div>
<div class="item">fixed</div>
<div class="item">fixed</div>
style.css 
.item.grow {
  flex: 1 0 auto;    /* claims all leftover space */
}
