Fluid Typography with clamp()

Minimum, preferred, maximum — text scales smoothly with the viewport instead of jumping at breakpoints.

clamp() — Resize the Window

Minimum, preferred, maximum. The heading never shrinks below 1.5rem or grows past 3rem — between those, it scales smoothly with the viewport.

Fluid Heading

index.html 
<p class="heading">Fluid Heading</p>
style.css 
.heading {
  /* minimum, preferred (viewport-based), maximum */
  font-size: clamp(1.5rem, 3vw + 0.75rem, 3rem);
}
