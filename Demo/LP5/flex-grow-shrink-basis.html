DT 5.3

flex-grow, flex-shrink, flex-basis

The three numbers that decide exactly how a flex item resizes — the shorthand is grow shrink basis.

The flex Shorthand — Three Numbers

flex: grow shrink basis. Sidebar never grows and never shrinks below 200px. Main content claims all remaining space.

Sidebarflex: 0 0 200px
Main contentflex: 1 1 auto
index.html 
<div class="sidebar">Sidebar</div>
<div class="main">Main content</div>
style.css 
.row { display: flex; gap: 1rem; }

/* grow: 0, shrink: 0, basis: 200px — fixed width, never changes */
.sidebar { flex: 0 0 200px; }

/* grow: 1, shrink: 1, basis: auto — fills whatever space is left */
.main { flex: 1 1 auto; }
