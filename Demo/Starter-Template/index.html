Skip Link — Try Tabbing to It

Required on every page, before anything else in the body. Click the label below, then press Tab — the link is the very next stop and will slide into view the instant it's focused.

The Full HTML Shell

Copy this as-is to start any new page. Nothing in it is optional.

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <!-- Skip link: the FIRST focusable element on the page. -->
  <!-- Lets keyboard users jump past the nav straight to main content. -->
  <a class="skip-link" href="#main">Skip to main content</a>

  <header>
    <!-- Site branding / logo goes here -->
  </header>

  <nav>
    <!-- Primary site navigation goes here -->
  </nav>

  <main id="main">
    <!-- This page's unique content goes here -->
  </main>

  <footer>
    <!-- Copyright, secondary links, contact info -->
  </footer>

</body>
</html>

The Full CSS Shell

Reset, custom properties, base styles, the skip link, focus visibility, and the reduced-motion reset — every project starts here, every time.

style.css 
/* ============================================
   RESET & BOX MODEL
   Apply to every project, every time.
   ============================================ */
*, *::before, *::after {
  box-sizing: border-box;
}

body {
  margin: 0;
}

/* ============================================
   CUSTOM PROPERTIES
   Define your palette and fonts once, here.
   ============================================ */
:root {
  --color-primary: #0B3D54;
  --color-text: #1B2A35;
  --color-bg: #FFFFFF;
  --font-body: system-ui, sans-serif;
}

/* ============================================
   BASE STYLES
   ============================================ */
body {
  font-family: var(--font-body);
  color: var(--color-text);
  background: var(--color-bg);
  line-height: 1.6;
}

/* ============================================
   SKIP LINK
   Hidden off-screen until it receives keyboard focus.
   ============================================ */
.skip-link {
  position: absolute;
  top: -60px;
  left: 0;
  background: var(--color-primary);
  color: #fff;
  padding: 0.75rem 1.25rem;
  z-index: 100;
  text-decoration: none;
}

.skip-link:focus {
  top: 0;
}

/* ============================================
   FOCUS VISIBILITY
   Never remove this without a replacement.
   ============================================ */
a:focus-visible,
button:focus-visible,
input:focus-visible {
  outline: 3px solid var(--color-primary);
  outline-offset: 2px;
}

/* ============================================
   REDUCED MOTION
   Required on every project with any animation.
   ============================================ */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration:        0.01ms !important;
    animation-iteration-count: 1     !important;
    transition-duration:       0.01ms !important;
    scroll-behavior:           auto   !important;
  }
}
Why this exists: every one of these pieces is taught individually across Learning Plan 1 (semantic HTML, skip links, box-sizing, focus-visible) and Learning Plan 3 (reduced motion) — this page just puts them together in the order you'll actually type them, so you have one place to copy from instead of hunting across nine Learning Plans every time you start something new.
