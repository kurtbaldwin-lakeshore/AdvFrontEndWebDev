clip-path — Custom Shapes in CSS

Crop an element into a shape without touching the image file itself.

Circle
Triangle
index.html 
<div class="shape cp-circle">Circle</div>
<div class="shape cp-polygon">Triangle</div>
style.css 
.cp-circle {
  clip-path: circle(50% at center);
}

.cp-polygon {
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
}
