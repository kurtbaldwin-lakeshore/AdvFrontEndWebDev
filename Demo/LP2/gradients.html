Gradients

Linear and radial color transitions, plus a photo-overlay pattern for readable text.

Gradients

Linear gradients flow in a direction; radial gradients radiate from a point. Both can sit behind text — as long as contrast holds up at the gradient's lightest point.

Linear
Radial
index.html 
<div class="shape grad-linear">Linear</div>
<div class="shape grad-radial">Radial</div>
style.css 
.grad-linear {
  background: linear-gradient(135deg, #0b3d54, #a65314);
}

.grad-radial {
  background: radial-gradient(circle, #1b6b8c, #0b2733);
}

Gradient Overlay — Photo Pattern

A darkening gradient layered over a background image keeps text readable no matter how light the photo gets — check the lightest corner, not just the average.

Door County Sunset

Text stays readable at every point because the overlay is darkest exactly where the photo is lightest.

index.html 
<div class="grad-card">
  <div class="grad-card-overlay">
    <h3>Door County Sunset</h3>
    <p>Text stays readable at every point…</p>
  </div>
</div>
style.css 
/* Standing in for a real photo — swap for background-image: url() */
.grad-card {
  border-radius: 12px;
  overflow: hidden;
  background: linear-gradient(160deg, #a65314 0%, #0b3d54 100%);
}

/* The darkening overlay that keeps the heading readable */
.grad-card-overlay {
  background: linear-gradient(rgba(11,39,51,.55), rgba(11,39,51,.75));
  padding: 2rem;
  color: #fff;
}
