border-radius

One property, three completely different looks depending on the value and the element's proportions.

Rounded12px
Circle50%
Pill999px
index.html 
<div class="shape br-rounded">Rounded</div>
<div class="shape br-circle">Circle</div>
<div class="shape br-pill">Pill</div>
style.css 
/* All four corners equally */
.br-rounded { border-radius: 12px; }

/* Perfect circle — requires equal width and height */
.br-circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}

/* A large value simply clips at the shortest side */
.br-pill { border-radius: 999px; }
