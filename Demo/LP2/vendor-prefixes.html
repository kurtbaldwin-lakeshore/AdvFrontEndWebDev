Vendor Prefixes — What Still Needs One

Most properties from this Learning Plan need zero prefixes today. A few specific properties — shown below — still commonly need -webkit-. Always verify on caniuse.com before assuming.

Outlined Text

Gradient Heading Text

index.html 
<div class="vp-stroke">Outlined Text</div>

<h3 class="vp-gradient-text">Gradient Heading Text</h3>
style.css 
/* Outlined text effect — still needs -webkit- */
.vp-stroke {
  -webkit-text-stroke: 1px #a65314;
  color: transparent;
}

/* Gradient text — the -webkit- prefix is still required */
.vp-gradient-text {
  background: linear-gradient(90deg, #145a78, #a65314);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
