opacity & rgba

Two ways to fade an element — and why they behave very differently on child content.

opacity vs. rgba — Two Different Fades

opacity fades the element AND everything inside it. rgba() fades only the color it's applied to — child text stays fully opaque. Both boxes below sit on the same backdrop so the difference is visible.

opacity: 0.5

rgba(0,0,0,.5)

index.html 
<div class="op-backdrop">
  <div class="op-box op-opacity">
    <p>opacity: 0.5</p>
  </div>
</div>

<div class="op-backdrop">
  <div class="op-box op-rgba">
    <p>rgba(0,0,0,.5)</p>
  </div>
</div>
style.css 
/* opacity affects the element AND all its children — */
/* the text inside fades right along with the background */
.op-opacity {
  background-color: black;
  opacity: 0.5;
}

/* rgba() affects ONLY the background — child text stays crisp */
.op-rgba {
  background-color: rgba(0, 0, 0, 0.5);
}
