transform-origin

Changing the point a transform pivots, scales, or rotates from.

transform-origin — Changing the Pivot Point

The default origin is dead center. Hover or focus each button below — all three rotate the same amount, but from a different point.

index.html 
<button class="shape to-center">Center</button>
<button class="shape to-topleft">Top Left</button>
<button class="shape to-bottom">Bottom</button>
style.css 
.to-center:hover,
.to-center:focus-visible {
  /* transform-origin: center is the default — no need to set it */
  transform: rotate(8deg);
}

.to-topleft { transform-origin: 0 0; }
.to-topleft:hover,
.to-topleft:focus-visible {
  transform: rotate(8deg);
}

.to-bottom { transform-origin: center bottom; }
.to-bottom:hover,
.to-bottom:focus-visible {
  transform: rotate(8deg);
}
