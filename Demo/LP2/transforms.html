Transforms

Move, rotate, scale, and skew — every example is keyboard-accessible, not just hoverable.

Transforms — Try Tabbing and Hovering

Every effect below responds identically to :hover and :focus-visible — keyboard users get the same feedback as mouse users.

index.html 
<button class="shape tf tf-translate">Translate</button>
<button class="shape tf tf-rotate">Rotate</button>
<button class="shape tf tf-scale">Scale</button>
<button class="shape tf tf-skew">Skew</button>
<button class="shape tf tf-combo">Combined</button>
style.css 
.tf-translate:hover,
.tf-translate:focus-visible {
  transform: translateY(-10px);
}

.tf-rotate:hover,
.tf-rotate:focus-visible {
  transform: rotate(8deg);
}

.tf-scale:hover,
.tf-scale:focus-visible {
  transform: scale(1.12);
}

.tf-skew:hover,
.tf-skew:focus-visible {
  transform: skewX(-8deg);
}

/* Combined transforms are space-separated, applied right to left */
.tf-combo:hover,
.tf-combo:focus-visible {
  transform: translateY(-6px) scale(1.08);
}
