Form Pseudo-Classes

The browser already tracks validation state — these pseudo-classes just let you style what it knows.

Form Pseudo-Classes

The browser tracks validation state automatically. Type an invalid then valid email below to see the border change live.

index.html 
<label for="fpc-email">Email</label>
<input type="email" id="fpc-email" required
       placeholder="you@example.com">
style.css 
/* :valid — input currently passes HTML5 validation */
.fpc-input:valid { border-color: #15803d; }

/* :invalid — fires immediately on load for empty required fields, */
/* so pair it with :not(:placeholder-shown) to wait until the user types */
.fpc-input:invalid:not(:placeholder-shown) {
  border-color: #dc2626;
}
