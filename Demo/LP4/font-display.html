font-display

Five values, each trading off differently between showing text immediately and showing it in the final font.

font-display — Five Values

The value controls what happens while a font loads. Local fonts load instantly, so these all render identically here — the point of this page is the correct syntax for each value.

auto — browser default, unpredictable

block — invisible text while loading (avoid)

swap — fallback shows immediately (recommended)

fallback — brief invisible period, then swap or give up

optional — uses cache only, may skip the web font

index.html 
<p class="fd-auto">auto</p>
<p class="fd-block">block</p>
<p class="fd-swap">swap</p>
<p class="fd-fallback">fallback</p>
<p class="fd-optional">optional</p>
style.css 
@font-face { font-family: 'FD-Auto';     src: local('Georgia'); font-display: auto; }
@font-face { font-family: 'FD-Block';    src: local('Georgia'); font-display: block; }
@font-face { font-family: 'FD-Swap';     src: local('Georgia'); font-display: swap; }
@font-face { font-family: 'FD-Fallback'; src: local('Georgia'); font-display: fallback; }
@font-face { font-family: 'FD-Optional'; src: local('Georgia'); font-display: optional; }

.fd-swap  { font-family: 'FD-Swap', serif; }
.fd-block { font-family: 'FD-Block', serif; }
