@font-face

One rule per weight/style — the font-family name is what you'll use everywhere else in CSS.

@font-face

This demo uses src: local() to reference a font already on your system, so it works fully offline — in a real project, src: url() would point to a font file you host. The syntax pattern is identical either way.

Before: default system font

After: @font-face applied

index.html 
<p class="ff-before">Before: default system font</p>
<p class="ff-after">After: @font-face applied</p>
style.css 
@font-face {
  font-family: 'DemoDisplay';  /* the name you'll use in CSS */
  src: local('Georgia'), local('Times New Roman');
  font-weight: 400;
  font-display: swap;
}

/* In a real project, src points to a file you host instead: */
/* src: url('/fonts/DemoDisplay.woff2') format('woff2'); */

.ff-after {
  font-family: 'DemoDisplay', Georgia, serif;
  font-size: 1.4rem;
}
