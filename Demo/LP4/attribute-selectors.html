Five patterns, each matching a different relationship between the attribute and its value.

Attribute Selectors — Five Patterns

Target an element by an HTML attribute's presence or value — no class or ID required. These links are styled purely by their href.

https:// link — starts with mailto: link — starts with Ends in .pdf — ends with Contains "twitter.com" — contains anywhere Has target="_blank" — presence only
index.html 
<a class="as-link" href="https://example.com">https:// link</a>
<a class="as-link" href="mailto:demo@example.com">mailto: link</a>
<a class="as-link" href="file.pdf">Ends in .pdf</a>
<a class="as-link" href="https://twitter.com/example">Contains twitter.com</a>
<a class="as-link" href="#" target="_blank">Has target="_blank"</a>
style.css 
/* [attr^="value"] — starts with */
a[href^="https"]  { color: #15803d; font-weight: 700; }
a[href^="mailto"] { color: #a65314; font-weight: 700; }

/* [attr$="value"] — ends with */
a[href$=".pdf"] { color: #7c3aed; font-weight: 700; }

/* [attr*="value"] — contains anywhere */
a[href*="twitter.com"] { color: #0369a1; font-weight: 700; }

/* [attr] — presence, any value */
a[target="_blank"] { text-decoration: underline wavy; }
