Sibling Combinators

Both target elements that come after another — the difference is how many.

Sibling Combinators

Descendant and child combinators target by hierarchy. Sibling combinators target by what comes AFTER an element at the same level.

A Heading

Adjacent (+): only this first paragraph is bold.

General (~): every paragraph after the heading is colored, including this one.

...and this one too.

index.html 
<h3>A Heading</h3>
<p>Adjacent (+): only this first paragraph is bold.</p>
<p>General (~): every paragraph after…</p>
<p>…and this one too.</p>
style.css 
/* General sibling (~): ALL matching elements after, same parent */
.sc-demo h3 ~ p { color: #a65314; }

/* Adjacent sibling (+): only the FIRST matching element right after */
.sc-demo h3 + p { font-weight: 700; }
