DT 4.2

::before and ::after Pseudo-Elements

Content is required — without it, neither pseudo-element renders at all.

::before and ::after

Both insert a virtual element — content is the one property that's always required, even if it's just an empty string.

Section With Accent

A decorative bar, inserted purely with CSS — no extra HTML element.

Design is not just what it looks like. Design is how it works.
index.html 
<h3 class="ba-title">Section With Accent</h3>

<blockquote class="ba-quote">Design is not just what it looks like…</blockquote>
style.css 
/* ::before — inserts a virtual element as the FIRST child */
.ba-title::before {
  content: '';
  display: block;
  width: 3rem;
  height: 4px;
  background: #a65314;
  margin-bottom: 0.5rem;
}

/* ::before with real text content — a large decorative quote mark */
.ba-quote::before {
  content: '"';
  font-size: 3rem;
  color: #a65314;
  line-height: 0;
  margin-right: 0.25rem;
  vertical-align: -0.4rem;
}
