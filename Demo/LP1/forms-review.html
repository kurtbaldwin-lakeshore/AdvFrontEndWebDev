Forms Review

The highest-stakes accessibility surface on any page — this should already be habit.

Labels — Programmatically Associated

Click the label text itself — focus jumps to the input. That only works when for/id are correctly paired.

index.html 
<label for="email">Email</label>
<input type="email" id="email" name="email" required>

fieldset + legend — Grouping Related Fields

A screen reader announces the legend before every field inside the group — "Shipping Address, Street" instead of just "Street."

Shipping Address
index.html 
<fieldset>
  <legend>Shipping Address</legend>
  <label for="street">Street</label>
  <input type="text" id="street" name="street">
</fieldset>
style.css 
fieldset {
  border: 2px solid #dbe7ea;
  border-radius: 8px;
  padding: 1.25rem;
}
legend {
  font-weight: 700;
  padding: 0 0.5rem;
  color: #0b3d54;
}

required — Paired With a Visible Cue

The required attribute alone isn't enough — sighted users need a visible marker too, not just the native browser validation message.

index.html 
<label for="phone">Phone <span class="required-mark">*</span></label>
<input type="tel" id="phone" name="phone" required>
style.css 
.required-mark {
  color: #dc2626;
  font-weight: 700;
}
