Specificity & the Box Model

Two Course 1 concepts that quietly cause most CSS debugging headaches — worth a fast, precise refresher.

Specificity — Four Rules, One Winner

All four rules below target the same paragraph and all set a different color. Only one wins — the one with the highest specificity, regardless of source order.

This text's color is decided by specificity.

index.html 
<p id="target" class="target" style="color: #a65314;">
  This text's color is decided by specificity.
</p>
style.css 
/* Specificity hierarchy, lowest to highest */
p              { color: #93c5fd; }  /* 0-0-1 */
.target        { color: #6ee7b7; }  /* 0-1-0 */
#target        { color: #0b3d54; }  /* 1-0-0 */
/* style="" on the element itself — beats all of the above */

The Box Model — Four Layers

Real CSS margin has no fill color — it's always transparent, so it can't be shown directly. The diagram below uses four nested, colored elements purely to make all four normally-invisible layers visible at once; the actual CSS for one real element looks like the panel underneath.

border
padding
content
index.html 
<div class="box">content</div>
style.css 
/* The real, single-element version of what the diagram above illustrates */
.box {
  margin: 2rem;      /* outermost — space outside the border, always transparent */
  border: 6px solid #a65314; /* the visible edge */
  padding: 1.25rem; /* space inside the border */
  /* content sits at the center — what width/height actually size */
  /* depends entirely on box-sizing, covered on CSS Baseline */
}
