Semantic HTML5

Required on every page, no exceptions — the structural and accessible baseline everything else builds on.

Skip Link — Try Tabbing to It

Required on every page. Invisible until a keyboard user tabs to it. Click the label below, then press Tab — the link is the very next stop and will slide into view the instant it's focused.

2. Skip to main content
index.html 
<a class="skip-link" href="#main">Skip to main content</a>
style.css 
/* Off-screen by default — doesn't affect sighted layout */
.skip-link {
  position: absolute;
  top: -60px;
  left: 0;
  background: #0b3d54;
  color: #fff;
  padding: 0.75rem 1.25rem;
}

/* Slides into view the instant it receives keyboard focus */
.skip-link:focus {
  top: 0;
}

The Required Landmarks

Every page needs these four — they're what lets a screen reader user jump straight to the part of the page they want.

<header>
<nav>
<main id="main">
<footer>
index.html 
<body>
  <header>...</header>
  <nav>...</nav>
  <main id="main">...</main>
  <footer>...</footer>
</body>

aria-current on the Active Link

Tells assistive technology — and gives you a CSS hook — which nav item represents the current page.

Home About Contact
index.html 
<nav>
  <a href="/" aria-current="page">Home</a>
  <a href="/about">About</a>
  <a href="/contact">Contact</a>
</nav>
style.css 
nav a[aria-current="page"] {
  font-weight: 700;
  border-bottom: 3px solid #a65314;
}
