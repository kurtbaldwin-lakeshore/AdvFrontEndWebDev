CSS Baseline

The patterns expected in every project from here on — not reviewed again after this.

Custom Properties in :root

Defined once, reused everywhere — change the value in one place and every box below updates.

--color-primary
--color-accent
index.html 
<div class="swatch primary">--color-primary</div>
<div class="swatch accent">--color-accent</div>
style.css 
/* In :root — always */
:root {
  --color-primary: #0D7A8A;
  --color-accent: #A65314;
  --font-body: 'Inter', Arial, sans-serif;
}

.swatch.primary { background: var(--color-primary); }
.swatch.accent  { background: var(--color-accent); }

box-sizing: border-box — First Rule, Always

Both boxes below have the SAME width and padding declared. Only box-sizing differs — watch how differently they end up sized.

content-boxgrows past 160px
border-boxstays exactly 160px
index.html 
<div class="box content-box">content-box</div>
<div class="box border-box">border-box</div>
style.css 
/* First rule, every project — apply globally */
*, *::before, *::after { box-sizing: border-box; }

/* Same width + padding on both — only box-sizing differs */
.content-box {
  box-sizing: content-box;
  width: 160px;
  padding: 1.5rem;
}
.border-box {
  box-sizing: border-box;
  width: 160px;
  padding: 1.5rem;
}

:focus-visible — Always Present

Tab to each element below. Never ship outline: none without a replacement — keyboard users need to see where they are.

A link
index.html 
<a href="#">A link</a>
<button>A button</button>
<input type="text">
style.css 
/* Always present — never outline: none alone */
a:focus-visible,
button:focus-visible,
input:focus-visible {
  outline: 3px solid var(--color-primary);
  outline-offset: 2px;
}
