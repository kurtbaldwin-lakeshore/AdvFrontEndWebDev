Bootstrap Navbar — The Correct Structure

Bootstrap's navbar uses <nav> for landmark accessibility, and requires the toggle button's ARIA attributes to work correctly for everyone.

The Correct Navbar Structure

Shrink the window below 768px — the links collapse behind a toggle button. Click it; the menu genuinely expands and collapses via Bootstrap's JS.

Brand Name
  • Home
  • About
index.html 
<nav class="navbar navbar-expand-md navbar-dark bg-primary">
  <div class="container">
    <a class="navbar-brand" href="/">Brand Name</a>

    <!-- Mobile toggle button -->
    <button class="navbar-toggler" type="button"
            data-bs-toggle="collapse" data-bs-target="#nav-menu"
            aria-controls="nav-menu" aria-expanded="false"
            aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>
    </button>

    <div class="collapse navbar-collapse" id="nav-menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item">
          <a class="nav-link active" aria-current="page" href="/">Home</a>
        </li>
      </ul>
    </div>
  </div>
</nav>
