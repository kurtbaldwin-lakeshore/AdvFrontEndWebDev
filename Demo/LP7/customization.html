Overriding Bootstrap With CSS Custom Properties

Bootstrap 5.3+ exposes its colors as CSS custom properties — override one variable, and every component using it updates, with no !important needed.

index.html 
<button class="btn btn-primary">Default Primary</button>
<button class="btn btn-primary" id="branded-btn">Overridden Primary</button>
style.css 
/* Bootstrap's own button CSS reads from --bs-btn-bg and --bs-btn-border-color — */
/* redeclare them scoped to one button, and Bootstrap's existing rules pick it up */
#branded-btn {
  --bs-btn-bg: #a65314;
  --bs-btn-border-color: #a65314;
  --bs-btn-hover-bg: #8a4511;
  --bs-btn-hover-border-color: #8a4511;
}
