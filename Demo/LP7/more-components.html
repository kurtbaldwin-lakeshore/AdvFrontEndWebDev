DT 7.4

Badge, Breadcrumb, Progress, List Group

Four smaller components, each with its own ARIA requirement for accessibility.

Badge

A small count or status label, usually paired with another element.

index.html 
<button class="btn btn-primary">
  Inbox <span class="badge bg-danger">4</span>
</button>

Breadcrumb

aria-label="breadcrumb" and aria-current="page" make the trail meaningful to screen readers, not just sighted users.

  1. Home
  2. Products
  3. Current Item
index.html 
<nav aria-label="breadcrumb">
  <ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="/">Home</a></li>
    <li class="breadcrumb-item active" aria-current="page">Current Item</li>
  </ol>
</nav>

Progress Bar

role and the aria-value* attributes let assistive tech announce the percentage — the visual bar alone isn't enough.

60%
index.html 
<div class="progress" role="progressbar"
     aria-valuenow="60" aria-valuemin="0" aria-valuemax="100">
  <div class="progress-bar" style="width: 60%">60%</div>
</div>

List Group

aria-current marks the active item, matching the same pattern used in navbar and breadcrumb.

  • Active item
  • Second item
  • Third item
index.html 
<ul class="list-group">
  <li class="list-group-item active" aria-current="true">Active item</li>
  <li class="list-group-item">Second item</li>
</ul>
