Card, Button, Modal, Alert

Four components you'll use constantly — all genuinely interactive via Bootstrap's own JS.

Card

Bootstrap's most-used component — a content container with a header/body/footer structure.

Card Title

Some quick example text for the card body.

Go somewhere
index.html 
<div class="card">
  <div class="card-body">
    <h5 class="card-title">Card Title</h5>
    <p class="card-text">Body text</p>
    <a class="btn btn-primary">Go somewhere</a>
  </div>
</div>

Button

Variants signal purpose — primary for the main action, outline for a secondary one.

index.html 
<button class="btn btn-primary">Primary</button>
<button class="btn btn-outline-secondary">Outline</button>

Modal — Click to Open

Genuinely opens via Bootstrap's JS — requires role="dialog" and aria-modal for accessibility.

Confirm Action
This is a real, working Bootstrap modal.
index.html 
<button data-bs-toggle="modal" data-bs-target="#demoModal">Open Modal</button>

<div class="modal fade" id="demoModal" tabindex="-1"
     aria-labelledby="demoModalLabel" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">...</div>
  </div>
</div>

Alert — Dismissible

Click the close button — Bootstrap's JS fades it out and removes it, no page code needed.

Warning message
index.html 
<div class="alert alert-warning alert-dismissible fade show" role="alert">
  Warning message
  <button class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>
