grid-template-areas

Naming regions of the grid so the layout reads like a diagram in your CSS.

grid-template-areas — Named Regions

Name each region, then draw the layout as ASCII art in the CSS itself — the shape of the rule matches the shape of the page.

header
sidebar
main
footer
index.html 
<div class="page">
  <div class="header">header</div>
  <div class="sidebar">sidebar</div>
  <div class="main">main</div>
  <div class="footer">footer</div>
</div>
style.css 
.page {
  display: grid;
  grid-template-columns: 160px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: 1rem;
}

/* Each item claims its named area — no line numbers needed */
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
