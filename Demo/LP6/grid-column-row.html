DT 6.1

grid-column and grid-row

Placing one item across specific tracks, even spanning multiple.

grid-column — Spanning Multiple Tracks

A 4-column grid. One item explicitly spans from line 1 to line 3 — two tracks wide — while the others take one track each.

Spans 2 columns
2
3
4
5
index.html 
<div class="grid">
  <div class="cell wide">Spans 2 columns</div>
  <div class="cell">2</div>
  <!-- 3 more cells -->
</div>
style.css 
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 1rem;
}

/* Occupies grid lines 1 through 3 — two tracks wide */
.wide { grid-column: 1 / 3; }

grid-row — Spanning Vertically

The same idea, on the vertical axis — one item spans two row tracks tall.

Spans 2 rows
2
3
index.html 
<div class="grid rows">
  <div class="cell tall">Spans 2 rows</div>
  <div class="cell">2</div>
  <div class="cell">3</div>
</div>
style.css 
.rows {
  grid-template-columns: repeat(2, 1fr);
  grid-template-rows: repeat(2, 80px);
}

/* Occupies grid row lines 1 through 3 — two tracks tall */
.tall { grid-row: 1 / 3; }
