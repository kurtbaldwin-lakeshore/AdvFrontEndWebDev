Defining tracks with the fr unit and repeat() — the foundation of every grid.

grid-template-columns — Defining Tracks

Three tracks: a fixed 100px sidebar, then two flexible tracks sharing the rest 1fr to 2fr.

100px
1fr
2fr
index.html 
<div class="grid">
  <div class="cell">100px</div>
  <div class="cell">1fr</div>
  <div class="cell">2fr</div>
</div>
style.css 
.grid {
  display: grid;
  grid-template-columns: 100px 1fr 2fr;
  gap: 1rem;
}

repeat() — Equal Tracks Without Repetition

repeat(4, 1fr) writes "four equal flexible tracks" without typing 1fr four times.

1
2
3
4
index.html 
<div class="grid repeat">
  <div class="cell">1</div>
  <!-- 3 more cells -->
</div>
style.css 
.repeat {
  grid-template-columns: repeat(4, 1fr);
}
