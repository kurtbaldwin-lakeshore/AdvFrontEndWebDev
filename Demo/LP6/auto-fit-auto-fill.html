DT 6.1

auto-fit vs. auto-fill

Identical syntax, different behavior when there are fewer items than would fill a row.

auto-fit vs. auto-fill — Only 2 Items

Same container, same minmax(140px, 1fr), only the keyword differs. With just 2 items in a wide row, the difference becomes visible: auto-fit stretches them to fill the space; auto-fill leaves room for invisible empty tracks, so they stay narrow.

<div class="grid fit">

</div>

  <div class="cell">1</div>
  <div class="cell">2</div>
</div>
style.css 
/* auto-fit: collapses empty tracks to 0 — existing items stretch */
.fit { grid-template-columns: repeat(auto-fit, minmax(140px, 1fr)); }

/* auto-fill: keeps empty tracks reserved (invisible but present) — items don't stretch to fill them */
.fill { grid-template-columns: repeat(auto-fill, minmax(140px, 1fr)); }

auto-fit — Resize the Window

No media queries. Columns are added or removed automatically as the container width changes — each one at least 140px, growing to fill remaining space.
