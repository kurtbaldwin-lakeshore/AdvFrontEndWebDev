aria-labelledby

aria-label writes a name inline; aria-labelledby points to an id of text that already exists and reuses it.

aria-labelledby — Reusing Visible Text

The heading is already visible on the page — aria-labelledby points to it and reuses it as the section's accessible name, instead of repeating the words in aria-label.

Pricing Plans

This section's accessible name IS this heading — not a separately written string.

index.html 
<section aria-labelledby="pricing-heading">
  <h3 id="pricing-heading">Pricing Plans</h3>
  ...
</section>
