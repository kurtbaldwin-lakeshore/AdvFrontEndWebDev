ARIA Attributes

Four attributes, four different jobs — a name, a state, a linked description, and a removal from the tree entirely.

aria-label — Name With No Visible Text

An icon-only button has nothing for a screen reader to announce — aria-label supplies the missing name.

index.html 
<button aria-label="Close dialog">&times;</button>

aria-expanded — Communicates State

Click to toggle — aria-expanded genuinely flips between true and false, exactly what a screen reader announces.

aria-expanded is currently: false

index.html 
<button aria-expanded="false">Toggle Menu</button>

aria-describedby — Links a Description

Focus the input — a screen reader announces the label, then the linked error text, automatically.

Valid email required

index.html 
<input type="email" aria-describedby="email-error">
<p id="email-error" role="alert">Valid email required</p>

aria-hidden — Removes From the Tree

The star icon is purely decorative — aria-hidden removes it from screen readers entirely, leaving only the real text.

★★★★☆ 4 out of 5 stars

index.html 
<span aria-hidden="true">★★★★☆</span>
<span class="sr-only">4 out of 5 stars</span>
