flex-basis: the starting width

Each box is told how wide to start. With grow and shrink both off (flex: 0 0 ...), the basis is the final width. The grey strip is the container, so you can see the empty space.

Putting it together: the card grid

The cards on the card page use flex: 1 0 280px. Read it left to right.

1 (grow)
Spare room in a row is shared, so the cards stretch to fill it.
0 (shrink)
A card is never squeezed below its basis. If the row is full, the card wraps instead.
280px (basis)
The starting width, and effectively the minimum, that decides how many cards fit per row.
