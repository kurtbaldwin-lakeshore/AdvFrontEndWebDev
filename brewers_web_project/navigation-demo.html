You Made It to the Main Content

This page exists only for classroom demonstration. The oversized navigation above gives keyboard users many links to move through before they reach this content.

Reload the page and use only the keyboard. On the first press of Tab, the skip link should appear. Press Enter and the browser moves directly here instead of requiring you to tab through the regular site navigation and all of the demonstration menu links.

What to Demonstrate

  1. Reload the page and press Tab once.
  2. Show the visible "Skip to main content" link.
  3. Press Enter and show that focus jumps to the main content.
  4. Reload again and ignore the skip link.
  5. Continue pressing Tab and observe how many navigation links must be visited.

Nested Navigation

The dropdowns are built with nested unordered lists. No JavaScript, Bootstrap, animations, or other advanced frameworks are used. The CSS uses basic positioning plus :hover and :focus-within so the menu can be demonstrated with both a mouse and keyboard.
